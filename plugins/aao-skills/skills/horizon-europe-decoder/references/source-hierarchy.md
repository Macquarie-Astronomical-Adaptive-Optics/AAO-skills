# Horizon Europe source hierarchy

Use current official sources. URLs and document versions can change, so verify them on every substantive run.

## Governing and operational sources

1. `Funding & Tenders Portal topic page`
   - Start at: https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/programmes/horizon
   - Use for the topic's live status, deadline, topic conditions, submission documents, updates, and direct topic URL.
2. `Current Horizon Europe work programme and General Annexes`
   - https://research-and-innovation.ec.europa.eu/funding/funding-opportunities/funding-programmes-and-open-calls/horizon-europe/horizon-europe-work-programmes_en
   - Use the relevant work-programme part and the General Annexes for the same programme period.
3. `Horizon Europe Programme Guide and participating-countries guidance`
   - Obtain the current versions from the Funding & Tenders Portal reference-documents area.
   - Use them for programme-wide participation, country, role, financial, and procedural guidance, subject to topic-specific conditions.
4. `Official application documents attached to the topic`
   - Part A forms, Part B template, budget workbook, model grant agreement, security or ethics annexes, FAQs, and call updates.
   - Match the document version and action type to the topic. Do not reuse an old template because its filename looks similar.
5. `Official EU agency and National Contact Point guidance`
   - General applicant overview: https://rea.ec.europa.eu/horizon-europe-who-should-apply_en
   - Use relevant agency or NCP guidance for clarification and support contacts.

## Programmatic discovery

The Funding & Tenders Portal documents public APIs at:

https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/support/apis

Check the current official API documentation before using endpoints or reference codes. Treat API results as discovery records and open the canonical topic page before making a decision-grade claim.

## Evidence record

For every source used, capture:

| Field | Required value |
| --- | --- |
| Source title | Human-readable official title |
| Source type | Topic page, work programme, General Annex, Programme Guide, template, update, or guidance |
| URL or path | Direct canonical location |
| Version/date | Document version and publication date, if shown |
| Access date | ISO date |
| Locator | Page, section, table, or portal field |
| Supports | Exact claim or output field supported |
| Status | Current, superseded, unclear, or local snapshot only |

## Source cautions

- Search-result snippets are not evidence.
- A work-programme PDF is a planning and topic-definition source, not a live status service.
- A call-level date or budget must not be silently assigned to every topic without checking the call/topic structure.
- A general participation guide does not override a topic-specific country, ownership/control, security, or consortium restriction.
- An accessible template does not prove that it is the template for the target topic or action type.
- The portal includes grants and procurement. Confirm which route the user is examining.
