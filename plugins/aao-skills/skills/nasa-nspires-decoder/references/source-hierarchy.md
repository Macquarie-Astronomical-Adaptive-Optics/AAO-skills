# NASA NSPIRES and ROSES source hierarchy

Use current official sources and record the access date.

## Operational sources

1. `NSPIRES opportunity record`
   - https://nspires.nasaprs.com/external/
   - Use `OPEN`, `FUTURE`, due-soon, and search views for live NASA research announcements, exact identifiers, displayed dates, documents, and points of contact.
2. `Current solicitation and program-element documents`
   - Download from the exact NSPIRES record.
   - For ROSES, read the current Summary of Solicitation plus the individual program element. The program element can add or override defaults.
3. `NASA Science funding opportunities and ROSES resources`
   - https://science.nasa.gov/funding-opportunities-and-announcements/
   - https://science.nasa.gov/researchers/
   - Use for the current ROSES cycle, subject/due-date tables, explanatory material, FAQs, and links to amendments.
4. `ROSES amendment and clarification record`
   - https://science.nasa.gov/researchers/solicitations/roses-blogs/
   - Use the page for the applicable cycle and check changes after the base PDF's publication.
5. `NSPIRES registration and submission guidance`
   - https://science.nasa.gov/researchers/sara/how-to-guide/nspires-registration/
   - Use for account, affiliation, organisation, AOR, release, and submission mechanics, subject to the current solicitation.
6. `US registration and submission systems`
   - https://sam.gov/
   - https://www.grants.gov/
   - Use only when the exact NASA opportunity makes them relevant.

## Source cautions

- NSPIRES lists multiple opportunity types; confirm whether the record is financial assistance, procurement, an RFI, or another instrument.
- ROSES is an umbrella with many program elements and date types.
- A program may accept rolling submissions even though NSPIRES displays the end of the current ROSES cycle.
- Foreign participation and foreign funding are different questions.
- Registration guidance does not establish eligibility for an award.
- A NASA news article or webinar is useful context but does not override the solicitation text or amendment.

## Evidence record

| Field | Required value |
| --- | --- |
| Opportunity | Exact title and identifier |
| Parent | ROSES cycle or other master solicitation |
| Source | NSPIRES record, summary, element, amendment, guidance, or registration system |
| URL | Direct official location |
| Version/date | Issue and amendment date |
| Accessed | ISO date, time, and timezone |
| Locator | Section, table, page, or portal field |
| Supports | Exact output claim |
| Status | Current, superseded, unclear, or snapshot only |
