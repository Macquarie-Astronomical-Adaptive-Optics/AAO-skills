# Changelog

## 0.3.0 - 2026-08-03

- Added a single-source installer for Claude Code and Codex: symlink-based on macOS/Linux and safe managed copies on Windows.
- Added `space-funding-router` for cross-platform space-project funding triage.
- Added source-first decoders, opportunity templates, and evaluation cases for NASA NSPIRES/ROSES, ESA OSIP/esa-star, and Australian Space Agency/GrantConnect/ARC routes.
- Documented the official EU Funding & Tenders public API and a cautious survey of hosted MCP services and community Horizon-oriented skills.
- Added a five-slide briefing on the dual-agent design, field-test results, funding-platform coverage, and proposed live pilot.

## 0.2.0 - 2026-08-03

- Added the `horizon-europe-decoder` skill for source-bound scheme explanation, opportunity discovery, topic decoding, eligibility and participation checks, strategic matching, and application mapping.
- Added reusable opportunity and organisation-profile templates, official-source and decoder references, evaluation cases, and a tested local work-programme topic indexer.
- Field-tested the decoder against six additional European Commission documents plus Lee Spitler's Cluster 4 source; added document-family diagnosis, ECCC topic handling, PCP/PPI/COFUND action types, and an evidence record of results and limitations.

## 0.1.0 - 2026-05-05

- Created the initial AAO reusable skills repository structure.
- Added Claude Code marketplace and plugin manifests.
- Added Codex install script and Claude Code install notes.
- Added starter skill folders for `aarc-grant-writing`, `paper-downloading`, `infrared-shaped-mirror`, and `telescope-creation`.
- Added space-telescope concept, geometry-honesty, STOP closure, space-environment screening, requirements/budget/verification, and manufacturing-package sanity skills.
- Expanded the AARC grant-writing workflow around discovery, Markdown source capture, user confirmation, critical review loops, and final format conversion.
