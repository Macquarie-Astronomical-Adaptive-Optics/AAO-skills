# Security Policy

Report security or confidentiality issues privately to the repository maintainers.

Do not file public issues or pull requests containing secrets, credentials, unpublished proposal content, partner-private material, controlled information, Defence-specific priorities, internal strategy, reviewer notes, or clearance assumptions.

Before adding content to this repository, check that it is safe for broad AAO and approved-collaborator circulation. Put sensitive material in `AAO-restricted-skills` instead.
